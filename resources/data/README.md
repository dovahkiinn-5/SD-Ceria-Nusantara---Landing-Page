## Data wilayah untuk formulir pendaftaran

`indonesia-regions.json` adalah snapshot 20 Oktober 2026 dari [API Wilayah Indonesia v2](https://github.com/emsifa/api-wilayah-indonesia), yang mengagregasi data [cahyadsn/wilayah](https://github.com/cahyadsn/wilayah). Kedua proyek menyatakan lisensi MIT. Snapshot ini hanya memuat kode dan nama 38 provinsi serta 514 kabupaten/kota; tidak memuat koordinat atau data pribadi.

Perbarui snapshot ketika ada perubahan administrasi wilayah. Ketentuan domisili dan kuota penerimaan harus mengikuti juknis yang berlaku untuk sekolah; kode wilayah di sini hanya membantu pengelompokan pendaftar.
